Layout da Placa IGNLOCK

Diagrama de posicionamento e fiação ponto a ponto para a placa fenolite ilhada/perfurada (PCB1, 70×90 mm — ver docs/02-bom.md), em escala real. Referência elétrica: docs/01-hardware-schematic.md.

Isto não é um Gerber de fábrica Este é um guia de posicionamento + fiação para montagem manual (ponto a ponto) em placa fenolite ilhada ou perfurada com módulos prontos (ESP32 DevKit, buck, RTC) — os furos exatos de cada módulo variam por fornecedor, então os fios saem de pontos nomeados, não de furos pré-perfurados específicos. As trilhas de alta corrente (bateria, saída para a bomba) devem ser feitas com fio de bitola adequada soldado direto (ver docs/02-bom.md, Tabela A.2.1) — nunca por cobre fino de placa. Se quiser fabricar uma placa de cobre roteada de verdade (JLCPCB/PCBWay), o próximo passo é abrir um projeto KiCad/EasyEDA — posso ajudar a começar isso quando quiser.
